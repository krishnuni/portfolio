Read their [agent policy](https://github.com/is-a-dev/register/blob/main/AGENTS.md), [documentation](https://docs.is-a.dev/) and [terms](https://is-a.dev/terms). No registration branch or pull request has been submitted on the user's behalf.

## Records explained

After checking availability, a registration for the preferred name would use `domains/vai.json`. The owner username identifies `krishnuni`. GitHub Pages' CNAME target is `krishnuni.github.io`, without `https://`, a repository name or a trailing path. Follow the current service documentation to write and submit the request yourself.

## After approval

1. In this portfolio repository's **Settings → Pages**, set the approved custom domain after the request is merged, as instructed by the service.
2. Follow GitHub's verification guidance if a TXT record is required. Use the exact value supplied by GitHub.
3. Set the repository variable `SITE_URL` to the confirmed public address, including `https://` and the final slash. `actions/configure-pages` supplies the base path for the same build to work at a project path or custom-domain root.
4. Confirm DNS and HTTPS, then check the homepage, three case studies, CV and shared links at the actual address.

Attach the domain to this project repository. Do not change the account-wide user site's domain; Hush, Gateway and Search Atlas retain their established project URLs.
