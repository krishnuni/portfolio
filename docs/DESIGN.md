# Design

A harmonious mineral palette, selected after visual review:

| Token   | Colour    | Role                                         |
| ------- | --------- | -------------------------------------------- |
| Ink     | `#142D30` | Main text, primary controls, Gateway chapter |
| Teal    | `#36565A` | Active details and surface shading           |
| Mineral | `#ABC3BF` | Quiet depth and secondary surfaces           |
| Mist    | `#DAE5DF` | Architecture and reading transitions         |
| Pearl   | `#F2F1E9` | Background and clear reading surface         |

Figtree provides a consistent identity. Large, closely set headings establish scale; body text stays open. Hush's display treatment references its publication character. Actual app typography is preserved inside captures.

## Composition

Identity, role, work and résumé are visible immediately. The analytic surface is progressive enhancement. A ruled index leads to three different showcases: Hush's narrative/product spread, Gateway's dark viewport, and Search Atlas's working search study. Expandable notes expose concrete engineering choices. About, experience and contact are ordinary readable HTML.

Case studies use complete documents and standard URLs. Technical depth does not depend on an overlay or canvas.

## Interaction and access

The hero supports phase scrubbing, play/pause, reset and pointer orientation. Reduced motion and narrow layouts begin paused. Offscreen and hidden-document rendering stops.

The cutaway has named Experience/Structure buttons and a native range. Clipped content is inert until fully revealed; invisible links are kept out of keyboard order. The independent case-study architecture is always readable.

Search uses actual computed output. Its range replays visited history; route cost appears at a completed result. Editing uses buttons, arrow keys and Enter. The small study is explicitly distinct from the complete Search Atlas application.

Semantic landmarks, skip navigation, descriptive media, visible focus and native controls are part of the design. The phone menu is a disclosure. The reading study has named size and appearance controls. Clipboard success is announced only after the operation succeeds; the email link always remains available.

Phone-profile and narrow-frame checks are separate from physical-device certification.
