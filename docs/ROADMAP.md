# Portfolio roadmap

| Work         | Engineering evidence                                                           | Presentation                                           |
| ------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------ |
| Hush         | Product design, document handling, storage, on-device narration                | Flagship and permanent case study                      |
| Gateway      | Rust/WASM, numerical methods, independent validation, scientific visualisation | Scientific chapter and scoped case study               |
| Search Atlas | Algorithms, data structures, workers, deterministic replay, benchmarking       | Algorithm chapter, original small study and case study |
| Portfolio    | Responsive accessible interaction, progressive rendering, static delivery      | This new repository and Pages site                     |

Launch priorities are reliable project/CV links, complete case studies, operable interactions, responsive visual quality, reproducible builds and documented deployment. Add projects only when they supply a distinct competency and a working implementation. Maintain a smaller complete collection before expanding towards the broader 4–6-project goal.
